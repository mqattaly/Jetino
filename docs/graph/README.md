# گراف دانش پروژهٔ جتینو

یک «نقشهٔ کامل» از کد پروژه: هر تابع، کلاس، کامپوننت، جدول دیتابیس و فایل، به‌همراه
همهٔ رابطه‌هایشان (صدا زدن، import، ارث‌بری، خواندن/نوشتن جدول). با این نقشه لازم نیست
برای فهمیدن یک بخش، ده‌ها فایل را باز کنید: می‌توانید از یک نام شروع کنید و به همسایه‌هایش
برسید.

ساخته‌شده با [Graphify](https://github.com/Graphify-Labs/graphify) نسخهٔ `0.9.112` روی
کامیت `42ae7b7` — بدون ارسال هیچ خطی از کد به بیرون (پارس محلی با tree-sitter).

## از کجا شروع کنم؟

| می‌خواهم… | فایل |
|---|---|
| نقشه را با چشم ببینم و روی گره‌ها کلیک کنم | **`graph.html`** (بازکردن در مرورگر) |
| ساختار پوشه‌ها و فایل‌ها را درختی ببینم | `GRAPH_TREE.html` |
| جریان فراخوانی بین سرویس‌ها را ببینم | `CALLFLOW.html` |
| خلاصهٔ فارسی از معماری بخوانم | **`NAGHSHE.md`** |
| گزارش خودکار در سطح خام | `GRAPH_REPORT.md` |
| با ابزار پرس‌وجو کار کنم | `graph.json` + دستورهای پایین |

`graph.html` و `GRAPH_TREE.html` خودکفا هستند (کتابخانه‌ها در `vendor/` کنارشان است) و
بدون اینترنت باز می‌شوند. `CALLFLOW.html` دیاگرام‌هایش را با Mermaid از CDN می‌کشد، پس
برای آن به اینترنت نیاز است.

## داخل گراف چه چیزی هست؟

- **۲۰۶۹ گره** (تابع، کلاس، کامپوننت، فایل، جدول و ستون دیتابیس)
- **۴۵۲۰ یال** — ۹۶٪ استخراج‌شدهٔ قطعی از AST، ۴٪ استنتاج‌شده با اطمینان میانگین ۰٫۸۵
- **۱۱۰ جامعه** (خوشهٔ مفهومی) با نام فارسی
- ۱۱۸۳ گره در بک‌اند (`api/`) و ۳۸۴ گره در فرانت (`src/`)
- ۲۶ مایگریشن SQL هم ایندکس شده‌اند؛ جدول‌ها، ایندکس‌ها و ستون‌هایشان گره دارند

رابطه‌های پرتکرار: `contains` (۱۱۱۳)، `calls` (۸۵۴)، `imports_from` (۷۶۷)،
`references` (۷۰۳)، `imports` (۵۵۵)، `method` (۴۱۳)، `indexes` (۶۰).

## چه چیزی داخل گراف **نیست**؟

- **مستندات `docs/` و `PRD.md`**: ایندکس معنایی فایل‌های متنی به یک کلید مدل زبانی نیاز
  دارد که در زمان ساخت در دسترس نبود. اگر کلید داشتید، همین دستور آن‌ها را هم اضافه می‌کند:
  ```bash
  GEMINI_API_KEY=... graphify extract .        # بدون --code-only
  ```
- **فایل‌های CSS** (`style.css`، `next.css`، `liquid.css`، `tokens.css`): نسخهٔ فعلی
  Graphify CSS را پارس نمی‌کند؛ استایل‌ها از این نقشه بیرون‌اند.
- **تصاویر و `public/`**، و همچنین `node_modules/` و `dist/` و **خودِ `docs/graph/`**
  (طبق `.gitignore` و `.graphifyignore` — اگر خروجی گراف دوباره ایندکس شود، گراف به‌طور
  مصنوعی متورم می‌شود).
- متن فارسی داخل کدها در نقشه به‌صورت شناسه و مسیر فایل حاضر است، نه جست‌وجوی متنی کامل.

| `GRAPH_TREE.html` | ۱۱۴KB | درخت تاشوی فایل→نماد |
| `CALLFLOW.html` | ۲۸۲KB | ۱۶ دیاگرام جریان فراخوانی + ۱۵ جدول |
| `GRAPH_REPORT.md` | ۲۶KB | گزارش خودکار Graphify (انگلیسی) |

## پرس‌وجو از گراف (خط فرمان)

```bash
# یک‌بار نصب
python3 -m venv ~/.graphify-venv && ~/.graphify-venv/bin/pip install "graphifyy[sql]"

# چه کسی به این تابع وابسته است؟ (تحلیل اثر تغییر)
~/.graphify-venv/bin/graphify affected "GroceryService" --graph docs/graph/graph.json

# این نماد چیست و به چه چیزی وصل است؟
~/.graphify-venv/bin/graphify explain "OrdersService" --graph docs/graph/graph.json

# پرتأثیرترین گره‌های معماری
~/.graphify-venv/bin/graphify god-nodes --graph docs/graph/graph.json --top 20

# پرسش به زبان طبیعی روی گراف
~/.graphify-venv/bin/graphify query "order submission checkout" --graph docs/graph/graph.json
```

مسیر پیش‌فرض Graphify پوشهٔ `graphify-out/` است؛ چون این خروجی در `docs/graph/` نگه داشته
می‌شود، همیشه `--graph docs/graph/graph.json` را بدهید.

## به‌روزرسانی گراف بعد از تغییر کد

```bash
# سریع: فقط کدهای تغییرکرده دوباره استخراج می‌شوند (بدون هزینه، بدون کلید)
graphify update .

# کامل و از صفر با نام‌های فارسی (همان چیزی که این پوشه را ساخته)
bash scripts/graph/build-graph.sh
```

اسکریپت `scripts/graph/build-graph.sh` کل مسیر را اجرا می‌کند: استخراج AST، نام‌گذاری
فارسی جوامع (`scripts/graph/labels-fa.py`)، خوشه‌بندی، ساخت گزارش و HTML‌ها، و لوکال‌کردن
کتابخانه‌ها. خروجی هر بار بازنویسی می‌شود؛ اگر تفاوت‌ها منطقی بود کامیت کنید.

> نام جوامع با یک قاعدهٔ ساده بر اساس مسیر فایل‌ها ساخته می‌شود، نه با مدل زبانی؛ پس
> تقریبی است. اگر جایی نام گمراه‌کننده بود، جدول `API`/`APP` در `labels-fa.py` را اصلاح کنید.

## مجوزها

Graphify با مجوز Apache-2.0، vis-network با مجوز MIT و d3 با مجوز ISC منتشر شده‌اند؛
فایل‌های `vendor/` بدون تغییر از بسته‌های رسمی همان نسخه‌ها کپی شده‌اند
(`vis-network@9.1.6`، `d3@7.9.2`).
